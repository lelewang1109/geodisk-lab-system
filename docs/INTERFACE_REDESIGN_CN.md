# GeoDisk Lab 顶会型界面与实验联动设计说明

## 1. 为什么参考系统显得“高级”

AirVis 和 Compass 的成熟感并不主要来自控件数量，而来自完整的分析叙事。它们先提供空间或时间上下文，再让用户选择分析对象，随后用一个占主导地位的视图呈现核心模式，最后通过局部关系和时间证据解释结果。每个面板都回答一个明确问题，视图之间通过选择、过滤、悬停和时间游标联动，因此界面看起来像研究工具，而不是指标看板。

参考系统还共享以下视觉语言：

- 白色或极浅灰背景只承担结构作用，颜色主要编码数据语义。
- 主视图最大，辅助视图以小倍图、嵌入图或按需浮层出现。
- 同一语义在全部视图中保持同色，避免“一个模块一种颜色”。
- 边框细、阴影克制、文字层级明确，数据标记比容器更醒目。
- 结果通过图形证据直接呈现，数值只在选择后用于解释。

## 2. 旧界面的主要问题

旧版把空间映射、年度状态、迁移路径和指标卡并列放置，四个区域权重接近，缺少首要视觉问题。全局地理上下文占比过小且与主图脱节，大量硬指标长期占据屏幕，但没有回答“这些数值对应哪个区域、哪条边、哪个月份”。过小字号、大片空白、模块化的蓝紫配色和重复卡片进一步削弱了论文系统应有的视觉层级。

因此，本次重构不再增加常驻指标，而是把指标转化为选择对象后的诊断证据。

## 3. 新的信息架构

界面按论文图版组织为四个连续阶段：

| 区域 | 分析问题 | 主要内容 |
| --- | --- | --- |
| A Context | 当前研究哪个区域和数据？ | 全局区域图、数据集、分析镜头、月份与编码选择 |
| B Transform | 地理对象如何映射到圆盘/圆环？ | 地理参考、最终 Power 分区、缩放平移、单元选择与邻接叠加 |
| C State | 固定几何上的时间状态如何变化？ | S1/S2/S3 小倍图、月度曲线和联动月份 |
| D Diagnose | 哪些邻接被保留、丢失或新增？ | 参考/最终邻域对照、路径证据和选择对象的局部指标 |

主视图始终保留最大面积。年度状态和路径不是与主图竞争的独立页面，而是可以被提升到主视图的分析镜头。这样既保持单屏，也允许用户沿同一任务链深入分析。

## 4. 配色与图形编码

本系统采用接近参考论文系统的低饱和语义配色：

- 蓝色 `#2f789f`：参考关系、被保留邻接和主要连续值。
- 珊瑚红 `#d76552`：邻接丢失、方向变化和当前时间位置。
- 薄荷绿 `#78bcae`：最终图中新出现的关系、共享状态。
- 琥珀色 `#e7a63a`：当前选择和需要注意的对象。
- 冷灰白：页面结构、辅助网格和非活动对象。

颜色表达“关系状态”而不是“系统模块”。同一条边在地图、圆盘和局部关系图中使用相同颜色，降低跨视图认知成本。

## 5. 已实现的交互闭环

| 用户操作 | 联动结果 | 分析目的 |
| --- | --- | --- |
| 点击全局区域 | 切换 CEG 区域数据并重置到圆盘主视图 | 从全球/区域上下文进入局部实验 |
| 切换数据集 | 加载空间、气候、不规则行政区或天文数据快照 | 检查跨类型稳定性 |
| Map / Disk / Annulus | 在参考地理与最终映射间切换 | 比较变换前后几何与拓扑 |
| 点击单元 | 更新邻接边、局部关系图、节点指标和时间曲线 | 把全局结果落到可解释对象 |
| 滚轮缩放、拖动 | 检查密集区域和边界单元 | 完成细节按需分析 |
| 点击月份或曲线 | 更新主图标量编码和当前数值 | 追踪固定几何上的时间变化 |
| 点击 S1/S2/S3 | 将状态小倍图提升到主视图 | 比较年度状态模式及重叠 |
| 点击路径步骤/省份 | 更新流场、时间步骤和支持边 | 检查区域迁移路径证据 |
| 打开参数实验室 | 配置下一次可复现实验 | 把界面探索转化为后端实验条件 |

## 6. 参数分层

参数必须区分“即时视觉参数”和“需要重新运行算法的实验参数”。前者改变视图，不改变科研结果；后者必须由后端保存配置、运行并生成新的结果目录。

### 即时视觉参数

- 数据集与区域。
- Geographic Map / Disk / Annulus 表示。
- Topology / States / Flow 分析镜头。
- 标量值、节点保真度、边界/内部编码。
- 月份、选中单元、邻接叠加、缩放和平移。

### 后端重运行参数

- 4 邻域或 8 邻域参考模型。
- 接触容差 `ε`，建议报告 `1e-6` 至 `5e-4` 的敏感性。
- 是否使用共享边界长度作为邻接权重。
- 圆盘/圆环径向层数。
- 面积变异系数惩罚与其他目标函数权重。
- 固定候选日程、随机种子和优化预算。

界面只预览候选目标函数和下一次实验配置，不把滑块变化伪装成已经重新计算的几何结果。

## 7. 后端实验应如何补充

下一阶段建议围绕“最终 Power Diagram 的真实邻接是否改善”组织，而不是继续增加孤立指标。

1. **最终几何邻接评价**：从最终 Power 单元提取 `display_edges`，与地理参考邻接直接比较，不再用中间槽位图替代。
2. **边界/内部误差分解**：分别报告 boundary 与 interior 节点的 Precision、Recall、F1、方向误差和邻居顺序准确率，并给出两组差异的置信区间。
3. **共享边界长度加权**：将长公共边界视为更重要的邻接，报告 weighted precision/recall/F1，同时保留二值结果。
4. **4/8 邻域敏感性**：所有数据集使用相同候选日程和预算，对比结论是否依赖邻域定义。
5. **接触容差敏感性**：绘制 `ε`—F1、`ε`—新增边和 `ε`—丢失边曲线，避免由数值阈值制造结论。
6. **局部失败案例**：对最低 F1 的边界节点输出参考/最终邻域小图，形成可解释的 failure taxonomy。
7. **目标函数消融**：逐项移除方向、角度、径向、面积均匀性和最终邻接项，报告性能与运行时间变化。
8. **参数稳定性**：跨随机种子报告均值、标准差、95% bootstrap 置信区间和排名稳定性。
9. **跨数据类型验证**：分别覆盖规则格网、不规则行政区、气候场、天文网格和合成压力测试，不用单一平均值掩盖类型差异。
10. **用户研究**：围绕邻接查找、状态比较、路径追踪和异常定位设计任务，记录正确率、完成时间、NASA-TLX 以及交互日志。

## 8. 论文中建议报告的图表

- 系统总览图：A–D 四阶段界面及交互箭头。
- 主结果表：数据集 × 方法，报告几何合法性、二值/加权邻接、方向和顺序指标。
- 边界/内部哑铃图：直接展示两类节点的性能差距。
- 4/8 邻域与 `ε` 敏感性曲线。
- 目标函数消融热图或平行坐标图。
- 三个代表性局部案例：成功、边界失败、拓扑修复后改善。
- 用户研究任务表现与主观负担图。

## 9. 当前结论边界

当前系统已经支持几何合法性、跨数据类型浏览和最终几何邻接诊断。年度状态与迁移路径来自固定的既有实验快照，用作跨阶段探索证据，不应被表述为每次空间参数变化后已经自动重新计算。正式论文结论仍应保持为：几何合法性和跨数据稳定性成立，拓扑邻接优势尚待通过最终 Power 邻接目标、误差分解和敏感性实验验证。
